# DSSATLM-AgNeSy

This is the code repository for the DSSAT-LM proof-of-concept proposed in the paper [Closing the Gap Between Crop Simulation and Practical Decision-Making](https://doi.org/10.1016/j.compag.2026.111655):

```
Kpodo, J., Nejadhashemi, A. P., Kordjamshidi, P., Eeswaran, R., & Dong, Y. (2026). Closing the gap between crop simulation and practical decision-making. Computers and Electronics in Agriculture, 247, 111655.
```

## Demo

Please check out this [recording](https://www.loom.com/share/291e886a8350406e8e7f9a230a66832e) of the proof of concept in action. 
We are actively working on making it publicly accessible online.
