# DSSATLM-AgNeSy

This is the code repository for the DSSAT-LM proof-of-concept proposed in the paper [Closing the Gap Between Crop Simulation and Practical Decision-Making]().

```
Kpodo, J., Nejadhashemi, A. P., Kordjamshidi, P., Eeswaran, R., and Dong, Y. "Closing the Gap Between Crop Simulation and Practical Decision-Making". Accepted for publication in Computers and Electronics in Agriculture. 2026.

```
